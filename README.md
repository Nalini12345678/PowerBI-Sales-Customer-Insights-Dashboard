
# 📊 Retail Sales & Customer Insights Dashboard (Power BI)

## 🔹 Project Overview
This project presents an interactive Power BI dashboard analyzing retail sales, profitability, customer segmentation, and regional performance.

## 🔹 Dataset Features
- 500+ Records
- Customer Segments (Consumer, Corporate, Home Office)
- Product Categories (Electronics, Furniture, Appliances)
- Discount & Cost Analysis
- 6 Months Time Period

## 🔹 Key KPIs
- Total Sales
- Total Profit
- Profit Margin %
- Average Order Value (AOV)
- Month-over-Month Growth
- Total Orders

## 🔹 Analysis Performed
- Sales Trend Analysis
- Customer Segment Performance
- Regional & Category Matrix
- Top 5 Products by Sales
- Discount Impact on Profit

## 🔹 Tools Used
- Power BI Desktop
- DAX
- Excel
- GitHub

## 🔹 Business Insights
- Identified top-performing product categories
- Analyzed profitability across regions
- Evaluated discount impact on margins
- Observed monthly sales growth trends
